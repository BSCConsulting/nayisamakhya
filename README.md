# Nayi (నయి)

Civic digital home for Telangana & Andhra Pradesh — Phase 1 UI foundation (tokens, Header, Hero).

## Stack

- React + Vite
- Tailwind CSS v3

## Run locally

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Phase 1 scope

- Design tokens in `tailwind.config.js` (canvas, surface, ink, terracotta accent)
- Global styles in `src/index.css` (canvas body, hairline borders, tabular numerals)
- Floating frosted `Header`
- Open warm-canvas `Hero` with Telugu/English CTAs
